## 🏆 Standout Features

### 1️⃣ **Advanced AI-Powered Concept Graph** 🌐

The crown jewel of the application - an intelligent visual knowledge network.

#### What It Does
Automatically analyzes your documents and creates an interactive graph showing:
- **8-15 key concepts** extracted by AI
- **Semantic relationships** (8 types: causes, requires, influences, etc.)
- **Importance scoring** (1-10 scale)
- **Category classification** (Core Topic, Entity, Process, etc.)
- **Searchable keywords** (2-4 per concept)

#### Why It's Awesome
✨ **Visual Learning**: See relationships at a glance
✨ **Smart Layouts**: 3 algorithms (Force, Circular, Hierarchical)
✨ **Interactive Exploration**: Click nodes → instant questions
✨ **Search & Filter**: Find concepts in milliseconds
✨ **Rich Metadata**: Importance, categories, keywords
✨ **Professional Design**: Color-coded, size-based hierarchy

### 2️⃣ **Confidence Metrics** 📊

Know exactly how reliable each AI answer is.

#### What You Get
Every response includes:
- **Match Score** (0-100%): How well chunks match your question
- **Source Coverage** (0-100%): % from document vs. inference
- **Per-Source Confidence**: Individual chunk scores

#### Visual Indicators
```
🔵 90-100% = Excellent match
🔵 75-89%  = Good match
🟡 60-74%  = Fair match
🔴 <60%    = Weak match

🟣 80-100% = Highly grounded
🟣 50-79%  = Moderately grounded
🟡 20-49%  = Lightly grounded
⚪ 0-19%   = Conversational
```

#### Why It Matters
- **Trust**: Know when to trust the AI
- **Transparency**: See where answers come from
- **Quality**: Identify when to ask differently
- **Learning**: Understand AI reasoning

### 6️⃣ **Smart Document Processing** 🔍

Intelligent parsing and chunking.

#### Features
- **Format Detection**: Auto-identifies file type
- **Text Extraction**: Handles complex PDFs
- **Smart Chunking**: 800 chars, 100 overlap
- **Metadata Preservation**: Filename, date, size
- **Vector Embeddings**: High-quality semantic search

#### Processing Pipeline
```
1. Upload → Validate format
2. Extract → Parse content (PDF, DOCX, TXT)
3. Clean → Remove noise, fix encoding
4. Chunk → Split into 800-char segments (100 overlap)
5. Embed → Generate vectors (1024 dimensions)
6. Store → Save in Weaviate
7. Index → Enable fast retrieval
8. Ready → Available for queries
```

#### Quality Assurance
✅ Handles scanned PDFs (OCR if needed)
✅ Preserves formatting clues
✅ Maintains context across chunks
✅ Removes duplicates
✅ Validates encoding

### 🔟 **Vector Search** 🎯

State-of-the-art semantic retrieval.

#### Technology
- **Weaviate**: Production-grade vector database
- **Cohere Embeddings**: 1024-dimension vectors
- **Cosine Similarity**: Finds semantic matches
- **Top-K Retrieval**: Best 3-5 chunks per query

#### Why It's Better Than Keyword Search
```
Keyword Search (Old Way):
  Q: "How do we increase revenue?"
  Finds: Documents with "increase" AND "revenue"
  Misses: "growth", "boost sales", "expand income"

Semantic Search (Our Way):

  Understands: "growth strategies", "sales expansion",
               "profit optimization", "income generation"
  Finds: All semantically related content
```

## 🚀 Quick Start

```bash
# 1. Clone & Setup
git clone <repo>
cd ask-your-document

# 2. Backend
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1  # Windows
pip install -r requirements.txt
# Add COHERE_API_KEY to .env
uvicorn main:app --reload

cd ../frontend
pnpm install
pnpm dev

# 4. Use!
Open http://localhost:5173
Upload documents
Start exploring!
```
